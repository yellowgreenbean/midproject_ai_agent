# 가이드북 형식 (새 파일)

덧붙일 때는 맨 위 제목·안내 대신 `# N부 — <제목>` 과 「1부와 달라진 점」 표로 시작하고, 장 번호를 이어 쓴다.
`<...>` 는 채울 곳이다. 해당 없는 절은 지우지 말고 「해당 없음 — 이유」 한 줄로 남긴다.

````markdown
# 가이드북 — <기능 이름> (<기능 번호들, 예: PROD-F01 · F02>)

> 이 문서만 보고 **혼자서** <기능>을 리뷰하고, 다시 만들고, 띄우고, 확인할 수 있게 쓴 기록이다.
> 만든 날: <YYYY-MM-DD> · 기획서 근거: `docs/기획서.md` <Part · 장>
> 리뷰 기준: <커밋 `abc1234` 이후 | 커밋 안 된 작업 트리 (YYYY-MM-DD)>
````
