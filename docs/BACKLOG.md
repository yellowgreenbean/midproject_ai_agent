## 더미 카드에 발급일 채우기 (보류, 2026-11-11)
- **무엇**: `data/dummy/cards/cards.json` 카드 30장의 `resIssueDate`(발급일)가 모두 빈 값이라 `user_cards.issued_at` 이 NULL 이다. 발급일을 채우고(회원 가입·연결 계좌 개설 뒤 날짜), 연회비 청구 예정일을 기획서 식 `next_annual_fee_date = issued_at + n년`(Part 4 1-1-8)으로 `scripts/load_dummy.py` 에서 계산하도록 바꾼다. `scripts/check_dummy.py` 에 날짜 순서 검사(회원 가입 → 계좌 개설 → 카드 발급 → 첫 승인)를 더한다.
- **지금은**: 청구 예정일을 `scripts/seed_scenarios.py` 가 「지금」 기준으로 넣는다 — card_002 는 30일 뒤(알림 시연), card_003 은 오늘(청구 시연), 나머지 신용카드는 카드 번호순으로 2~11개월 뒤(사용자 결정 2026-11-11). 카드 상세의 발급일은 `issued_at` 이 없어 행을 만든 시각(`created_at`)이 보인다.
- **왜 보류**: 발급일을 지어 넣으면 더미 정합성 규칙(날짜 순서)을 새로 맞춰야 하고, 실제 발급일 기준이면 시연 시점에 알림·청구가 뜨는 카드가 없을 수 있다.
- **다시 시작할 조건**: 신용카드 발급(CARD-F06)을 만들어 발급일이 실제로 생기거나, 더미 카드 데이터를 다시 만들 때. 그때 시드의 청구 예정일 UPDATE(`annual_fee_dates`)는 시연용 두 장만 남기거나 지운다.
