# 세션 메모 — 2026-11-06 (RAG 문서 변환 다듬기)

이 세션에서 내가 한 질문·낸 아이디어와 그 결과. 회고 작성용.

## 1. 질문: OCR 로 추출할 때의 예외 상황 코드 리뷰 (`scripts/pdf_to_md.py`)

실제 PDF 로 돌려서 확인한 문제:
- **OCR 방향 분류(`use_cls`)가 바로 선 가로줄을 180° 뒤집는다.** `09월`→`60`, `9개월`→`H∠6` 으로 읽고, 줄 전체가 점수 미달로 버려지기도 한다. → `"Global.use_cls": False` 로 끄면 해결.
- **글자 수(30자 미만)만 보고 스캔본으로 판정한다.** `cards/해외전자상거래인증시스템이용약관.pdf` 8쪽은 글자층 23자("본 약관은 2026년 09월 10일부터 시행합니다.")가 있는데도 OCR 경로로 가고, 위 문제와 겹쳐 그 문장이 **경고 없이 사라졌다.**
- **OCR 결과가 비어도 경고가 없다.** 로그에는 `OCR: 페이지 1` 로 성공처럼 찍힌다.

코드만 읽고 찾은 문제(재현은 안 함):
- OCR 호출에 예외 처리가 없어서 그림 하나가 실패하면 PDF 전체가 실패한다. 이때 예전 `.md` 가 그대로 남는다.
- 그림을 잘라낼 때 좌표를 페이지 안으로 제한하지 않는다(음수 좌표·빈 이미지).
- 그림 안에 글자층이 한 자만 있어도 그 그림의 OCR 을 건너뛴다.
- 모델 다운로드가 실패하면 PDF 마다 다시 시도한다.

**상태:** 리뷰만 했고 `pdf_to_md.py` 는 아직 고치지 않았다. `cards/` 를 변환하기 전에 위의 앞 세 가지를 고쳐야 한다.

## 2. 아이디어: 상품설명서의 '※ 위 그림은' 그림을 OCR 해서 md 에 넣기

- 배경: 중도해지이율 구간 그래프가 이미지라서 md 에는 "※ 위 그림은 … 표현한 것입니다" 문구만 남고 그래프 내용은 빠져 있었다.
- 진행 방식: `prod_003` 하나로 먼저 해 보고, 선택할 것이 생기면 물어보기로 했다.
- 내가 고른 것:
  - md 에 넣는 형식: **구간별 문장**. 예: `계약일~3개월: 연0.1% · 3개월~6개월: 기본이율×50%×보유일수/계약일수 · … · 만기일: 약정이율`
  - 구현 위치: `pdf_to_md.py` 를 고치지 않고 **products 용 스크립트를 따로** 만들어 `scripts/` 에 둔다.
- 결과:
  - `scripts/products_figure_ocr.py` 를 만들었다. 방향 분류를 끄고, 다시 실행해도 문장이 중복되지 않는다.
  - `prod_003.md` 에 반영했다. 원본 그림과 비교해 모두 일치했다.
- 남은 일:
  - 이 문구가 있는 **나머지 23개 파일(28곳)**에 적용하기. `py -3.13 scripts/products_figure_ocr.py data/rag/products`. 앞서 "28개 파일"이라고 한 것은 틀렸고, 28은 곳의 수다.
  - md 들이 아직 커밋되지 않았으니 돌리기 전에 커밋하기.
- 알아 둘 점:
  - 그래프 내용은 같은 표의 '중도해지이율' 칸에 글자로 이미 들어 있다.
  - `pdf_to_md.py` 로 md 를 다시 만들면 넣은 문장이 사라지므로 이 스크립트를 다시 돌려야 한다.

## 3. 아이디어: 예금보호 FAQ 의 질문에 Q 번호 붙이기 (`data/rag/guides/deposit_protection_faq_kdic.md`)

- 요청: `?` 로 끝나는 문장 앞에 `Q1.`, `Q2.` … 를 붙인다. 이 파일만 고치고 다른 파일은 만들지 않는다.
- 결과:
  - Q1~Q17 을 붙였다.
  - PDF 추출 때 앞 문장과 한 줄로 합쳐진 질문 2개(Q5 `외화예금도 보호되나요?`, Q6 `보험계약은 어떻게 보호되나요?`)는 질문이 시작되는 곳에 붙였다.
- 남은 결정: `Q12. ※ 별도 보호한도란?` 은 질문이 아니라 설명 문구다. 이것을 뺄지 정해야 한다. 빼면 뒤 번호가 하나씩 당겨진다.
- 알아 둘 점: Q1 줄은 원래 글자가 깨져 있다("예금보호한도예금 1자억보호원제은도 F 언AQ제부터…"). 손으로 고쳐야 한다.
